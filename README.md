## 📝 How to Use This Repository

### **For Lab Files**
1. Navigate to `lab-files/`
2. Open the relevant `SET#_Analysis/` folder
3. View PNG for quick preview
4. Open TWBX in Tableau for interactive analysis

### **For CO Assessments**
1. Navigate to `CO_Assessments/`
2. Find your CO folder (CO1-CO5)
3. Place assessment files in the appropriate `Assessment_#/` subfolder
4. Update README.md with submission details
